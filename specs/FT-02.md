# FT-02 Kalkulator Berat & Info Minimum Charge

Sumber PRD: Bagian 5 (BL-01), Bagian 6 (FT-02), Bagian 8 (AC-01), Bagian 9 (TC-01), Bagian 12

## Tujuan
Pengguna dapat memasukkan estimasi berat cucian kiloan (kg) melalui tombol tambah/kurang atau ketik manual dan langsung melihat penerapan aturan berat minimal 3,0 kg.

## Alur
1. Saat paket kiloan dipilih, kolom berat cucian kiloan aktif dengan berat awal `3,0` kg atau dapat diubah oleh pengguna.
2. Pengguna menekan tombol `-` / `+` (langkah `0,1 kg`) atau mengetik angka berat (menerima koma dan titik).
3. Jika berat bernilai di antara `0,1` kg hingga `2,9` kg, aplikasi menampilkan penanda info bahwa berat ditagih mengikuti batas minimal `3,0 kg`.

## Data
- `STORE_CONFIG.minChargeKg` (`3.0`)
- `WEIGHT_GUIDE_TEXT` (`"10–12 potong kaos dewasa ≈ 2 kg"`)

## Aturan dan rumus
- Input berat aktual $W_{\text{aktual}}$: angka desimal kelipatan $0,1\text{ kg}$ ($\ge 0$). Input negatif ditolak atau dinormalkan ke `0`.
- Jika tidak ada paket kiloan dipilih atau $W_{\text{aktual}} = 0$, maka $W_{\text{ditagih}} = 0$.
- Rumus BL-01:
  - Jika $W_{\text{aktual}} > 0$, maka $W_{\text{ditagih}} = \max(3.0, W_{\text{aktual}})$.
  - Jika $W_{\text{aktual}} = 0$, maka $W_{\text{ditagih}} = 0$.
- Pembulatan: berat aktual dibulatkan ke 1 angka desimal terdekat (`Math.round(val * 10) / 10`), sedangkan subtotal rupiah dibulatkan ke bilangan bulat terdekat (`Math.round`).

## Input dan validasi
- Kolom input berat memakai `type="text"`, `inputMode="decimal"`, ukuran teks minimal `16px`.
- Menerima pemisah koma (`,`) dan titik (`.`), karakter selain angka/pemisah dibersihkan, nilai negatif ditolak dengan pesan error singkat beserta contoh (`"Masukkan berat 0,1 kg atau lebih, misalnya 2,5."`).
- Jika pengguna memilih paket kiloan tetapi mengosongkan berat menjadi `0`, status paket kiloan dihitung `0` kg (atau pengguna dapat mengubahnya kembali).

## Tampilan dan teks
- Tombol `-` dan `+` berukuran minimal `44 × 44 px`.
- Badge status amber (`bg-amber-50 text-amber-800`) dengan ikon informasi muncul otomatis bila $0 < W_{\text{aktual}} < 3.0$: `"Batas minimal 3,0 kg berlaku (ditagih 3,0 kg)."`
- Panduan visual ringan dari PRD ditampilkan di bawah kolom berat: `"Panduan: 10–12 potong kaos dewasa ≈ 2 kg"`.
